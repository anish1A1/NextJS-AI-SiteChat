installed Tanstack Query for managing asynchronous server-state, client side caching, and background refetching.

TanStack Query
Role: Async state manager and data-fetching cache.
What it does: Fetches, caches, synchronizes, and updates server state in your components using hooks like useQuery without dictating your routing or file structure.
Scope: Client-side (though it supports hydration from a server).
--> npm install @tanstack/react-query
